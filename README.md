# 📚 Biblioteca Digital UniFECAF

![Status do Projeto](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)


Este projeto representa a construção da primeira interface web para a **Biblioteca Digital da UniFECAF**, desenvolvido como desafio prático e acadêmico da disciplina de Design Web. 

**Objetivo e Contexto do Projeto**  
A missão principal foi transformar um protótipo de baixa fidelidade em uma plataforma moderna, funcional e totalmente responsiva construída do zero. A interface foi desenhada para facilitar o acesso dos estudantes ao acervo literário, visualizar informações das unidades físicas e encontrar os canais de contato, tudo isso respeitando rigorosamente a identidade visual (azul, preto e branco) e os padrões de usabilidade da instituição.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível do conteúdo.
- **CSS3 / SCSS:** Estilização avançada e modular utilizando variáveis globais, Flexbox e CSS Grid.
- **Design Responsivo:** Layout adaptável para smartphones através de Media Queries (foco em *mobile-friendly*).

## ✨ Principais Funcionalidades

- **Menu Mobile Interativo:** Navegação dinâmica no estilo "hambúrguer", exibindo as opções em uma lista suspensa translúcida.
- **Cards Inteligentes:** Organização do acervo de livros e unidades em grids que se reajustam automaticamente conforme o tamanho da tela.
- **Navegação Fluida:** Comportamento de página única (SPA) utilizando links âncora com rolagem suave (`scroll-behavior: smooth`).
- **Fidelidade Visual:** Contraste adequado, legibilidade e aplicação fiel da paleta de cores corporativa da UniFECAF.
